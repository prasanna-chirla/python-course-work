OOP's Concepts in Python

1. Class
A blueprint or template that contains attributes (variables) and methods (functions).
Example: Student class with name and age as attributes, and display() as a method.

2. Object
An instance of a class that uses the class blueprint.
Example: student1 = Student()

3. Encapsulation
Binding data (variables) and methods (functions) into a single unit (class) and providing security to the data.

4. Inheritance
Acquiring the properties and methods of a parent class into a child class.
It helps in code reusability.

5. Polymorphism
Same action, different behavior.
The same method behaves differently for different objects.

6. Abstraction
Hiding the implementation (complexity) and showing only the necessary information to the user.

Class → Blueprint of an object.
Object → Instance of a class.
Encapsulation → Binding data and methods with data security.
Inheritance → Parent class properties are acquired by the child class.
Polymorphism → Same action, different behavior.
Abstraction → Hide complexity, show only relevant information.
