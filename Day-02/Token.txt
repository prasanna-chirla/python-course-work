Token
A token is the smallest unit (part) of a Python program.
Identifier
Literal
Keyword
Operator
Punctuation
Statement
A statement is a single instruction that Python executes.
Example:
x = 10
print(x)
Comment
Comments are used to explain the code. Python ignores comments while executing the program.
Single-line Comment: 
Starts with #
# This is a single-line comment
Multi-line Comment:
 Uses triple quotes ''' ''' or """ """
'''
This is a
multi-line comment
'''
Identifier/variable:
An identifier is the name given to a variable, function, class, etc.
Rules:
Can contain A–Z, a–z, 0–9, and _ (underscore).
Cannot contain special characters like @, #, $, %, etc.
Must start with a letter (A–Z or a–z) or _ (underscore).
Cannot be a Python keyword (like if, for, while).
Case-sensitive (name and Name are different).
example:
n=10
if num % 2 == 0:
    print("Even")  
else:
    print("Odd")

Categories in this program
Identifiers: num, print
Keywords: if, else
Operators: =, %, ==
Literals: 10 (or input value), 2, 0, "Even", "Odd"
Punctuation (Punctuators): :, (, )
keywords::
